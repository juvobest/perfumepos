# PerfumePOS

A Windows-based Point of Sale (POS) and Inventory Management System for a perfume and gift-items business.

## Features

- Point of Sale
- Inventory Management
- Product Management
- Supplier Management
- Customer Management
- Sales History
- Receipt Generation
- Thermal and A4 Receipt Printing
- Multiple Payment Methods
- Discount Management
- Role-Based Access Control
- Audit Logging
- Reports
- Offline-First Operation

## Technology Stack

- Python
- PySide6
- SQLAlchemy
- SQLite
- Alembic
- Pydantic
- Pytest
